Where Is Jev?

Storage tank detection in one aerial image with pretrained models and no task training

The name is a play on Where's Waldo? When you look for Waldo, you scan the page left to right, top to bottom, until you find the cell he's in. Only then do you zoom in and actually spot him.

Same idea here. What if I break the image into small cells and hand each one to a Jev-style model? It tells me whether the cell has something, nothing, or just part of something. If it's nothing, I don't waste time running SAM 3 on it. If it's something, the cell goes to SAM 3 (or any object detector) to do the real work.

That's the whole project: a little experiment to try that out. So far it looks good; the numbers are below.

1. Summary

This project finds storage tanks in one aerial image. It uses pretrained models only. It does not train a model for this task.

The method has two stages:

  1. A vision-language model (VLM) makes a decision for each tile. The decision is one of three: the tile contains a tank, contains part of a tank, or contains no tank. This stage is the gate.
  2. SAM 3 makes detections in the tiles that contain all or part of a tank.

The project compares the detections with the labels in the Tanks layer. Each stage that uses a model runs on all GPUs of one host at the same time.

Results with the Qwen3-VL 32B gate (section 5 gives all values):

  • SAM 3 matches 82 of 85 labels at IoU 0.5 or more (recall 96.5%). All 85 labels touch a detection.
  • Precision is 36.6%. 132 of the 142 false positives do not touch a label. Many of them are small round objects. Nobody examined these objects.
  • The full run takes approximately 47 s on four GPUs. With the Qwen3-VL 4B gate, it takes approximately 25 s, with the same F1 (53.1%).

3. Method

  1. Tiles. patch_decisions.py prepare divides the image into tiles of 512 × 512 pixels. The stride is 256 pixels, so adjacent tiles overlap by 50%. The image gives 736 tiles. One point on the ground is in a maximum of four tiles.
  2. Gate. The VLM gets one tile and one fixed question (below). The question has three answers: A, B and C. The decision is the letter with the highest next-token score. Qwen3-VL uses one forward pass (transformers). Nemotron uses one constrained greedy token (vLLM). No classifier head is trained.
  3. Detection. patch_decisions.py gate sends the tiles with decision A or B to SAM 3. SAM 3 gets the text prompt “round storage tanks”. It gives a mask and a score for each object. detect.py uses a score threshold of 0.3. It converts each mask to a polygon. This polygon is a detection.
  4. Suppression. Overlapping tiles give the same tank more than once. merge_shards.py collects the detections from all tiles and sorts them. Detections that do not touch a tile edge come first, then detections with a higher score. The merge removes a detection when its intersection with a kept detection is more than half of the smaller area.
  5. Evaluation. evaluate.py uses only the labels and detections that have a centroid inside the extent. It matches each detection to a maximum of one label, in score order. A match needs an IoU of 0.5 or more. Areas use UTM zone 37N (EPSG:32637).
  6. Package. to_gpkg.py writes the layers to one GeoPackage for ArcGIS Pro.

Each model stage starts one model copy on each GPU. Each copy processes every n-th tile (rows[i::n]). The merge makes sure that each tile was processed exactly once.

Gate question

Classify this RGB overhead satellite image patch for circular industrial storage tanks.
A: Contains at least one complete storage tank whose full circular footprint is visible inside the patch.
B: Contains part of one or more storage tanks cut off by a patch edge or gray missing-image area, but no complete tank.
C: Contains no visible storage tank, either complete or partial.
If both complete and partial tanks appear, choose A. There may be one tank or many.
Partial means spatially cut off, not uncertain. Roads, factory roofs, ships, ponds, and bare ground are not storage tanks.
Gray regions are missing image data. Judge visible evidence only.
Answer with exactly one letter: A, B, or C.

4. Tile decisions

The project makes a reference value for each tile from the labels. A tile is “contains” when a label is fully inside the tile. A tile is “partial” when a label overlaps the tile and no label is fully inside. All other tiles are “none”. The project scores only the 513 tiles that are fully inside the extent: 89 contains, 93 partial and 331 none.

Presence counts contains and partial as positive. Presence values count tiles, not tanks.

7. Limits

NOTE: The results come from one image and one run for each configuration. They do not rank the models in general.

NOTE: Precision assumes that the Tanks layer has all tanks inside the extent. Figure 4 shows round objects without labels. If some of these objects are tanks, the true precision is higher.

NOTE: Suppression removes a detection that is inside a larger kept detection. A large false detection can remove a correct detection. No label lost its overlap in these runs.

NOTE: Qwen ran on gc1 with four GPUs. Nemotron ran on gc5 with two GPUs and a different runtime. Do not use these times as a controlled speed comparison.

NOTE: The project does not tune a prompt, threshold or weight on the labels.

8. Procedure

Do these steps to repeat the Qwen3-VL 32B run. gc1 must have data/Tanks.tif, the checkpoints in checkpoints/ and the .venv environment (see the README). Each command stops if its output exists. Use a new output name for each run.

On gc1

  1. Start a tmux session. 
    tmux new -s where-is-jev
  2. Go to the project folder. 
    cd ~/where-is-jev
  3. Run the gate decisions. The launcher runs 256, 384 and 512 px tiles on all GPUs. 
    bash run_tiles.sh qwen32b
  4. Make the gate folder from the 512 px decisions. 
    .venv/bin/python patch_decisions.py gate --manifest results/tiles/512/manifest \
  --shards results/tiles/512/qwen32b --out results/gate512_qwen32b
  5. Run SAM 3 and the merge on all four GPUs. 
    bash run_gc1.sh 32 results/sam3_qwen32b_512 results/gate512_qwen32b "round storage tanks"
  6. Make sure that the file results/sam3_qwen32b_512/COMPLETE exists.

On the local computer

  1. Copy the gate folder and the run folder from gc1. 
    scp -r gc1:where-is-jev/results/gate512_qwen32b gc1:where-is-jev/results/sam3_qwen32b_512 results/
  2. Set the data folder. 
    T=~/Documents/ArcGIS/Projects/Tanks
  3. Evaluate the detections. 
    .venv/bin/python evaluate.py --gdb $T/Tanks.gdb --image $T/Tanks.tif \
  --detections results/sam3_qwen32b_512/merged/detections.geojson --out results/sam3_qwen32b_validation
  4. Make the GeoPackage. 
    .venv/bin/python to_gpkg.py results/sam3_qwen32b_512/tank_detections.gpkg \
  detections=results/sam3_qwen32b_512/merged/detections.geojson \
  raw_detections=results/sam3_qwen32b_512/merged/raw_detections.geojson \
  gate_tiles=results/gate512_qwen32b/patches.geojson \
  evaluated_detections=results/sam3_qwen32b_validation/predictions.geojson \
  evaluated_tanks=results/sam3_qwen32b_validation/ground_truth.geojson \
  extent=results/sam3_qwen32b_validation/extent.geojson
  5. Make the figures. 
    .venv/bin/python figures.py --image $T/Tanks.tif --gate results/gate512_qwen32b \
  --merged results/sam3_qwen32b_512/merged --validation results/sam3_qwen32b_validation --out results/figures

11. Terms

TermMeaning in this document
TileA square of 512 × 512 image pixels. Adjacent tiles overlap by 50%.
GateThe stage that selects the tiles for SAM 3 from the VLM decisions.
DecisionThe VLM answer for one tile: A (contains a tank), B (contains part of a tank) or C (contains no tank).
DetectionOne polygon that SAM 3 makes for one object.
LabelOne polygon in the Tanks layer.
ExtentThe polygon in the Extent layer. Only labels and detections with a centroid inside it are scored.
SuppressionThe removal of duplicate detections after the merge of all tiles.
IoUIntersection area divided by union area of two polygons.
TP, FP, FNTrue positive: a detection with a matched label. False positive: a detection without a matched label. False negative: a label without a matched detection.
PresenceA tile value that is positive for contains and partial.
